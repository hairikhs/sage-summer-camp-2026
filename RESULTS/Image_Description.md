# HT-HC33 Camera Image

## Description

This image was captured using the Heltec HT-HC33 camera during the SAGE Summer Camp 2026 project.

## Communication Path

Heltec HT-HC33 Camera
→ Wi-Fi HaLow (IEEE 802.11ah)
→ Heltec HT-H7608 Gateway
→ Ethernet
→ SAGE Thor Node
→ SAGE Storage

## Significance

This image demonstrates successful end-to-end operation of the proof-of-concept system. The camera captured the image, transmitted it over a Wi-Fi HaLow link, the gateway forwarded it over Ethernet, and the image was successfully stored on the SAGE platform.
