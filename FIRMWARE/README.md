# HT-HC33 Firmware

This folder contains the firmware used during the SAGE Summer Camp 2026 project.

The firmware was shared by Ben Owusu-Amo to support understanding, testing, and future development of the Heltec HT-HC33 Wi-Fi HaLow imaging platform.

The source code is included as part of the project documentation so that future users can better understand how the system was implemented and extended.

## Folder Contents

### Source Files
- adaptive.c
- adaptive.h
- battery.c
- battery.h
- camera.c
- camera.h
- exif.c
- exif.h
- main.c
- mqtt_node.c

- storage.c
- storage.h

- send_config.py
